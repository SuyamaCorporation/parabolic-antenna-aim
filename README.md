# 09 パラボラアンテナ指向性計算機

## 概要
パラボラアンテナの口径・周波数・開口効率から利得(dBi)と半値角(HPBW)を計算。衛星の仰角・方位角も緯度経度から算出する電波工学ツール。

## 機能
- 口径(m)・周波数(GHz)・開口効率(η, デフォルト=0.6)を入力して利得・半値角を計算
- 利得(dBi) = 10×log₁₀(η×(π×D/λ)²)
- 半値角(°) = 70×λ/D
- 衛星仰角・方位角の計算フォーム（受信地点の緯度・経度・衛星経度から）
- BS/CS 110°E・124°E・128°Eのプリセットボタン
- 仰角が地平線以下の場合は受信不可警告を表示

## 技術仕様
- 静的SPA（HTMLシングルファイル）
- Tailwind CDN使用
- 計算式: 標準的な放物面アンテナ利得計算
- 静止軌道高度: 35786 km（地球中心から42164 km）
- 地球半径: 6371 km
- XSSガード: escapeHtml()関数によるサニタイズ
- localStorage不使用

## 使い方
1. `index.html` をブラウザで開く
2. 口径・周波数・開口効率を入力して「計算する」→利得・半値角が表示
3. 受信地点の緯度・経度とプリセット衛星を選んで「計算する」→仰角・方位角が表示

## 計算式詳細
| 項目 | 計算式 |
|------|--------|
| 波長 λ | c / f（c=3×10⁸ m/s） |
| 利得 G | 10×log₁₀(η×(πD/λ)²) dBi |
| 半値角 HPBW | 70×λ/D 度 |
| 仰角 El | arctan((cos(Δlon)cos(lat) - RE/GEO) / sqrt(1 - (cos(Δlon)cos(lat))²)) |
| 方位角 Az | 真北基準・時計回り（arctan2計算） |
